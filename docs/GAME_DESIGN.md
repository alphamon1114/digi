# 디지털 월드 비대칭 PvP

## 사용자 확정

디지털 월드 생존 경쟁을 다루는 독자 시나리오의 3인칭 3D 게임. 첫 시험은 악당 1 대 성장기 3, 최종 인원은 미확정.

- 악당은 야생 개체와 스캐빈저를 사냥해 데이터를 얻고 약 3단계로 영구 진화한다. 예시 메탈티라노몬 → 파워드라몬 → 카오스드라몬. 단계별 능력치·크기·공격 방식은 데이터로 정의한다.
- 다수 측은 공유 팀 경험치로 성숙기 → 완전체 → 궁극체를 해금한다. 실제 일시 진화와 에너지는 개인별이다. 퇴화해도 팀 경험치·해금은 유지된다.
- 다수 경험치 출처는 스캐빈저·하수인 처치, 야생 개체 대피 완료다. 대피 개체가 진화 데이터를 선물한다는 설정은 없다. 일시 진화의 세계관상 이유는 미정이다.
- 맵에는 대피 거점 3곳. 현장에서 진행하고 악당이 개입할 수 있다. 대피 완료 개체는 사냥 불가. 악당의 사냥 없이도 대피로 성장 가능.
- 야생 개체 사냥 장소에 지연 후 스캐빈저가 등장. 양측이 보상을 얻을 수 있으나 스캐빈저 사망으로 재생성되지 않는다.
- 대피가 실제 진행되면 독립된 하수인 보고 연출을 악당에게 보낸다. 위치·방향·거리·인원·진행률은 보내지 않는다. 보고는 현장 하수인 생존과 무관하며 소리는 비방향성이다. 그란드라큐몬 계열은 드라큐몬, 묘티스몬 계열은 피코데블몬. 기계 계열의 보고자는 임시 통신병.
- 배치형 하수인은 별개 시스템. 감지한 시점의 위치를 악당에게만 짧게 표시하고 범위 안에서 주기적으로 갱신한다. 다수 측은 제거·우회 가능.
- 다수는 구조 요청 후 탈출 또는 악당 토벌로 승리. 악당은 전멸로 승리.

## 개발상 임시 기본값 (D002)

`PrototypeConfig` Inspector 값을 최종 수치의 원본으로 사용한다. 호스트=악당, 최대 접속자 3명=다수. 호스트 시작 버튼으로 로비를 닫으며 이후 참가 불가. 연습 옵션은 빈 다수 슬롯을 봇으로 채운다.

HP 0이면 즉시 탈락, 부활 없음. 10분 제한 종료는 악당 승리. 접속 종료는 해당 캐릭터 탈락. 악당 연결 종료 시 세션 종료. 모든 야생 개체가 사냥 또는 대피로 해결되면 중앙 구조 장치가 활성화되고 20초 상호작용으로 생존 팀이 탈출한다. 사냥으로 대피가 모두 막혀도 구조 승리 경로는 남는다.

대피는 거점당 12초, 진행도 유지, 악당이 반경 5 안에 있으면 중단. 인원 추가로 가속하지 않는다. 거점당 야생 개체 2마리, 완료 시 살아 있는 개체당 경험치 35. 성숙기/완전체/궁극체 해금은 60/180/360. 첫 버전 실제 사용 가능 단계는 성숙기까지. 개인 에너지 100, 진화 중 초당 8 소모, 성장기 초당 5 회복, 진화 시작 최소 30. 전투 보상은 팀 전체에 한 번 합산한다.

야생 처치 데이터 40, 스캐빈저 처치 데이터/팀 XP 25, 하수인 팀 XP 20. 야생 처치마다 15초 후 스캐빈저 2마리, 각각 한 번 생성. 센서는 최대 3, 범위 12, 갱신 2초, 표식 3초. 센서 배치 재사용 5초. 보고는 각 거점 첫 진행 때 한 번, 여러 보고는 위치 없는 동일 연출로 합쳐 표시한다.

## 구현 상태

| 기능 | 상태 |
| --- | --- |
| 호스트/직접 IP 접속, 1대3 로비, 연습 봇 | 구현 |
| 3인칭 이동·회전·기본 공격·피격·장애물 | 구현, 기본 도형 표현 |
| 악당 사냥·데이터·3단계 영구 진화 | 구현, 타격/부채꼴/직선 공격 |
| 3거점 대피·경합·팀 XP | 구현 |
| 개인 성숙기 진화·에너지·퇴화 | 구현 |
| 완전체/궁극체 | 해금과 능력치 데이터 준비, 기본 사용 상한은 성숙기 |
| 지연 스캐빈저·양측 보상·재생성 방지 | 구현, 단순 추격/공격 AI |
| 독립 대피 보고 | 임시 초상/영문 자막/2D 신호음 구현, 거점 정보 없는 수신자별 이벤트 |
| 배치형 센서·주기 표식·파괴 | 구현 |
| 구조·토벌·전멸·시간 종료 | 임시 규칙으로 구현 |
| 전용 모델·애니메이션·다운/부활·공개 매칭 | 미구현/범위 밖 |

서버는 20Hz로 규칙과 이동을 계산하고 NGO 수신자별 JSON 스냅샷을 보낸다. 클라이언트는 의도 입력만 보내며 스냅샷을 도형/GUI로 표현한다. 일반 월드 액터는 공유되므로 경쟁 출시용 은닉/관심영역 보안은 후속 범위다. 대피 진행/보고와 센서 표식은 명시적으로 수신자 필터링한다.

## 미해결

최종 인원·밸런스, 개인 에너지 회복 방식, 쓰러짐/부활, 구조 세부 규칙, 제한시간, 상위 실제 진화, 미확정 진화 계열과 세계관상 일시 진화 이유, 전용 아트/애니메이션/음향.
